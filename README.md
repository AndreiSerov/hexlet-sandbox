### Итоги  

--- 
== - сравнивает ссылки на инстансы, т. е. если 
мы создаем два объекта с одинаковыми поля, то они будут
не равны, т к это два разных экземляра класса в памяти.

equals - нужно переопределять когда мы сравниваем 
кастомные объекты

hashCode нужно переопределять для предсказуемого поведния
функции. Если не переопределять, то даже объекты
с одиннаковыми полями 
будут с разными хэшами
